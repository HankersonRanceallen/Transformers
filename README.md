# Transformers
# Introduction to Transformers

## Overview

This project explores the fundamentals of Transformer architectures using Hugging Face Transformers and PyTorch.

The notebook demonstrates the complete Transformer workflow from text input to model output, including tokenization, embeddings, attention mechanisms, causal language modeling, and masked language modeling.

The exercises were completed using AMD MI300 GPU resources in the AMD Developer Cloud environment.

## Technologies Used

* Python
* PyTorch
* Hugging Face Transformers
* Qwen3-0.6B
* BERT
* AMD MI300 GPU

---

## Topics Covered

### Tokenization

Convert natural language text into tokens and token IDs that can be processed by transformer models.

### Embeddings

Transform token IDs into dense vector representations that capture semantic meaning.

### Attention Mechanism

Demonstrate how transformers use attention to understand contextual relationships between words.

### Context-Aware Representations

Explore how token representations change depending on surrounding context.

### Causal Language Modeling

Generate text one token at a time using a causal transformer architecture.

Examples:

* GPT models
* Claude
* Qwen

### Masked Language Modeling

Predict missing words using bidirectional context.

Examples:

* BERT
* RoBERTa
* DeBERTa
